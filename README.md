# VivoBoost P35

Toolkit Android ringan untuk memantau status perangkat Vivo Y12s (Helio P35) dan membuka pengaturan sistem yang relevan. Aplikasi ini tidak melakukan overclock, root, atau klaim RAM boosting.

## Build APK
GitHub Actions menjalankan `gradle assembleDebug` pada push ke `main` atau secara manual melalui tab Actions. APK debug tersedia sebagai artifact `VivoBoostP35-debug`.

## Fitur
- Ringkasan RAM, baterai, suhu baterai, dan penyimpanan.
- Pintasan ke pengaturan baterai, aplikasi, penyimpanan, Jangan Ganggu, dan layar.
- Panduan penggunaan gaming yang aman.

## Kebutuhan
- Android 6.0+ (minSdk 23).
- Java 17 dan Android Gradle Plugin 8.7.3 untuk build.

Status: source starter; build dan pengujian perangkat masih perlu diverifikasi.
